# 学生综合素质测评 Skill

这个 Skill 用于在收到：
- 素质测评规则/条例；
- 待填写的 Word/Excel 表格；
- 证明材料；
- 用户补充的关键信息；

之后，自动完成规则解析、材料核验、去重、计分、填表和结果校验，并输出填写完成的原格式表格。

主文件：`SKILL.md`


## Privacy

This repository contains only generic workflow instructions. It intentionally excludes real student names, IDs, institutions, project names, certificates, scores, contact details, uploaded evidence, and filled personal forms.
