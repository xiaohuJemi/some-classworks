# Privacy and publication safety

This skill is designed to be reusable without embedding source-case data.

The public package must not include:

- real names, student numbers or other identifiers;
- institution, college, class or internal organization identifiers from a source case;
- phone numbers, email addresses, mailing addresses or account information;
- certificate numbers, patent/application numbers, project names or uniquely identifying award details from a source case;
- screenshots, certificates, transcripts, filled personal forms or any other uploaded evidence;
- API keys, access tokens, local absolute paths, or hidden document metadata that identifies a source user.

At runtime, personal information may be read from user-provided materials only to complete that user's requested assessment form. It must not be persisted into the reusable skill itself.
